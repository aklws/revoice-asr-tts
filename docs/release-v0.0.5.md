# Revoice ASR-TTS v0.0.5 更新公告

发布日期：2026-07-13

## 本次更新重点

- 文本模式首段出声进一步提速：优化了流式合成时首个音频块的输出时机，减少“明明已经算出来了，但还要再等一下才出声”的情况。
- 改进后台预热：在加载完成或切换参考音频后，会提前做一次隐藏预热，减少第一次正式合成时的额外等待。
- 优化分段策略：文本分段默认进一步收紧，优先让语音更快开始播放，同时尽量保持整体流式体验。
- 首段策略更稳：首段采用更保守的生成方式，帮助降低首包阶段的随机波动。
- 新增实验性极速模式开关：在快速设置里可以手动开启更激进的加速方案；修改后会自动保存，并提示重启生效。
- 优化设置文案：实验性加速相关说明已改成更容易理解的用户语言，减少技术术语干扰。

## 细节调整

- 参考音频缓存日志更清晰：现在会区分热缓存、CPU 缓存和重新提取三种状态，便于判断当前是否命中缓存。
- 修正长度上限提示：只有在确实接近生成上限时才会给出告警，避免把正常的短分段误报成“撞上长度上限”。
- 流式合成链路继续保留已验证有效的性能优化，包括首段优先、异步声码器重叠和参考音频缓存。

## 设置与使用

- 快速设置中现在提供两个实验性加速选项：
  - `进阶模式`
  - `极速模式`
- 两个选项都会保存到本地设置中，修改后需要重启软件才会生效。

## 打包与版本

- 版本号已提升到 `v0.0.5`
- 项目元数据与界面显示版本已同步更新：
  - `pyproject.toml` -> `0.0.5`
  - `ui/main_window.py` -> `v0.0.5`
- Windows 打包脚本中的应用版本号也已同步更新：
  - `packaging/windows/build.ps1` -> `0.0.5 / 0.0.5.0`
  - `packaging/windows/build-installer.ps1` -> `0.0.5`

## 额外说明

- `极速模式` 更适合想优先追求响应速度的场景，但可能会占用更多显存。
- `进阶模式` 对运行环境要求更高，如果打开后效果不明显或出现异常，可以直接关闭并重启恢复常规模式。
- 本版本重点仍然是继续压低文本模式的首段等待时间，后续会继续围绕稳定性和段间衔接体验做优化。

## v0.0.5 后续更新

本版本发布后，围绕多语言模型、ASR 后端、说话人识别和高版本 `transformers` 兼容又补了几轮关键更新，当前实际行为以以下内容为准：

- `IndexTTS-2` 已补齐多语言模型切换能力：
  - 默认中英模型：`IndexTeam/IndexTTS-2`
  - 日语模型：`xmccln/IndexTTS-2-Japanese`
- 启动阶段会统一检查并自动准备所有启用的内置 `IndexTTS-2` 模型，而不再只检查当前选中的一个。
- 主界面的快捷设置已改成“输出语言”语义，不再直接暴露模型仓库名。
- 日语模型目录已加入增量包兼容补齐逻辑，缺失的基础文件会从官方模型目录自动补齐。
- `w2v-bert-2.0` 资源检查已加强为关键文件级校验，避免空目录误判“已就绪”。

### ASR 后端调整

- 默认 ASR 已从旧的 `Qwen3-ASR` 路线切到 `FunAudioLLM/Fun-ASR-Nano-2512`。
- 默认 ASR 推理后端为 `funasr.AutoModel`，并且默认设备改为 `cpu`，用于节约 GPU 显存。
- `vLLM` 仍然保留，但已改成实验性功能：
  - 快速设置里可切换 `启用实验性 ASR vLLM 后端`
  - 修改后需要重启软件
  - 开启时可通过 `ASR_VLLM_GPU_MEMORY_UTILIZATION` 与 `ASR_VLLM_MAX_MODEL_LEN` 控制显存占用

### 说话人识别与声纹过滤

- Live 模式的声纹过滤已从 TTS 侧自定义声纹提取改成 `CAMPPlus speaker verification`：
  - 模型：`iic/speech_campplus_sv_zh-cn_16k-common`
  - 默认目录：`checkpoints/speech_campplus_sv_zh-cn_16k-common`
- 当前仍保留原有滑窗、连续区间合并和首尾裁剪逻辑，但 embedding 来源已切换到专用 speaker 模型。

### 推理兼容修复

- 已修复 `transformers 5.x` 下 `IndexTTS` accel 路径的维度回归问题，避免 `GPT2Block.forward()` 返回值变化导致的 3D -> 2D hidden state 错误切片。
- 已移除这轮 accel 调试埋点，避免对 GPT 生成耗时造成额外拖慢。
- 已为 DAC 导入链补充兼容回退：
  - 主推理链不再因为 `audiotools` 缺失而直接崩溃
  - 训练/工具侧如果真的依赖 `audiotools`，仍需单独处理

### 依赖说明

- 当前主环境不建议重新装回 `descript-audiotools`
- 原因是它和 `vLLM` 在 `protobuf` 版本约束上天然冲突
- 当前运行时主链已经通过兼容修复绕开了这一依赖

### 输出语言与翻译节点

- 输出语言已从原先的“中英 / 日语”进一步细化为：
  - `中文`
  - `英文`
  - `日语`
- 其中 `中文` 和 `英文` 共用官方 `IndexTTS-2` 模型，`日语` 对应日语模型。
- 快速设置中已新增翻译节点配置区域：
  - 支持直接添加 `OpenAI`
  - 支持直接添加 `DeepSeek`
  - 支持添加和编辑自定义 OpenAI 兼容节点
- 开启翻译后，文本模式与麦克风模式都会在进入 TTS 之前，先把文本翻译成当前输出语言。
- 只有在切到 `日语` 或修改启动预下载模型清单时，才需要重启软件；在 `中文` 与 `英文` 间切换通常不需要重启。
